# Recursos Côvão — versão 4

- Menus principais apontam explicitamente para `index.html`, evitando listagens de diretórios.
- Os novos jogos seguem sempre a estrutura `index.html` + `dados.js` + `jogo.js`.
- O visual segue o template dos jogos existentes, com pequenas adaptações responsivas.
- Foram acrescentados novos jogos ao 1.º ano em Português, Matemática e Estudo do Meio.
- Os jogos usam as imagens já existentes nas pastas `img/animaisdomesticos`, `img/animaisselvagens`, `img/frutos` e `img/objetos`.
- Os layouts adaptam-se a computador, tablet e telemóvel.
